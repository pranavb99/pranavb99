# Building Foglight AI

I'm the founder of **Foglight AI**, an independent project exploring how AI can strengthen human judgment while improving organizational performance.

Foglight is a model-independent **evidence and decision-assurance system**. Its aim is to help people evaluate consequential claims by tracing evidence to its sources, examining competing explanations and counterevidence, preserving unresolved questions, and making the basis for decisions auditable.

## What I'm working on

- A **neuro-symbolic approach** combining AI interpretation with deterministic checks and persistent evidence and decision records.
- Prototypes and evaluations of selected assurance controls, including how conclusions should be reconsidered when their underlying evidence changes.
- Applications in **enterprise customer assurance, scientific research, and other evidence-intensive decisions**.

I'm especially interested in organizations where better AI can help people become **more capable independent decision-makers**, rather than passive approvers of automated answers.

**Project status:** Active development. Core source code and detailed technical materials remain in private repositories; this profile is a public overview.
